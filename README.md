# 🚗 Krs Vehicle Shop

A modern vehicle shop system for **FiveM** built with **QBox**, **ox_lib**, and **ox_inventory**.

---

### 📌 Description
**Krs Vehicle Shop** is an advanced dealership script for FiveM.  
It allows players to buy, test drive, and sell vehicles with a modern and optimized system.

---

### ⚙️ Features
- 🚘 Vehicle purchasing
- 💰 Vehicle selling with configurable percentage
- 🎨 Vehicle color selection
- 🔑 Automatic key system
- 🧾 Vehicle saving via `qbx_vehicles`
- 📍 Interactive zones using `ox_lib`
- 💵 Payment support:
  - Cash (`ox_inventory`)
  - Bank (`qbx_core`)
- 🚗 Smart vehicle spawning (collision-free)
- 🔒 Anti-exploit protections

---

### 📦 Dependencies
Make sure you have:

- [qbx_core](https://github.com/Qbox-project/qbx_core)
- [ox_lib](https://github.com/overextended/ox_lib)
- [ox_inventory](https://github.com/overextended/ox_inventory)
- [oxmysql](https://github.com/overextended/oxmysql)
- qbx_vehicles
- qbx_vehiclekeys
